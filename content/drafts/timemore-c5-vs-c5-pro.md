## 折りたたみは、日本の公式ショップの文

楽天の C5シリーズ商品ページ（2026年11月2日）は、C5 Pro と C5 ESP Pro が折りたたみ式ハンドル、と書いていました。C5（Proなし）を折りたたみとは書いていません。

日本公式のシリーズページの同梱品の行には、C5 / C5 Pro / C5 Esp / C5 Esp Pro と、折りたたみ式ハンドルが同じ塊で並んでいました。どの型に付くのかは、その行だけでは分かれません。ハンドルの違いを書くときは、楽天公式の文のほうを使います。

家の S5 Pro は折りたたみで、しまって小さい、という実感があります。それは S5 Pro の話です。C5 Pro を折りたたんだ感触は、分かりません。

## クリック幅は、C5とC5 Proで同じと書いてある

楽天公式は、C5 と C5 Pro を、1クリック0.031mm、48段階、とまとめていました。時計回りで細かく、反時計回りで粗い、とも書いていました。

日本公式の C5 Pro の欄は、1回転で全範囲、1クリック0.031mm、1回転48段階、です。仕様表は、マクロステップ16、全48クリック、最細設定3、です。

C3 の1回転12クリックとは、段の意味が違います。写し方は[C3とC5の違い](/drafts/timemore-c3-vs-c5)に置きます。何クリックでドリップするかは、測っていません。【よんぴー実測：C5 Proでハンドドリップ＝〇〇クリック】

## ESP Proは、この二台とは別

同じシリーズに、C5 ESP と C5 ESP Pro があります。楽天公式は、C5 ESP Pro を1クリック0.015mm、50段階、折りたたみ、と書いていました。日本公式の仕様表は、マクロ10、全50クリック、最細設定4、約640gです。

この記事の対は、C5 と C5 Pro です。ESP は、クリックの幅が違う別ダイヤルとしてだけ触れておきます。C5 ESP（Proなし）だけのクリック幅は、開いた説明では C5 ESP Pro と分かれていなかったので、【公式で未確認：C5 ESP（Proなし）のクリック幅】です。

## 英語公式は、呼び方が揃っていない

同じ日の英語公式（timemore.com）の選択肢は、C5 Pro が $110（ポアオーバー向け、とページが説明）、C5 Pro Esp が $115（より細かい設定と、引いて折りたたむハンドル）でした。Proなしの C5 は、その選択肢の取得文にはありませんでした。

日本の楽天公式は、折りたたみを C5 Pro と C5 ESP Pro の両方に書いています。英語公式のその日の文は、引いて折りたたむハンドルを C5 Pro Esp の説明に寄せていました。地域のページで、Pro という言葉の範囲が揃っていません。日本向けのこの下書きでは、楽天公式と日本公式のシリーズページを優先し、英語ページとの差はここに残します。買うときは、その店の型番表記を見てください。
