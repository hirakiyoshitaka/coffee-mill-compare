分享壺（也有人叫下壺）是放在濾杯底下、接萃取液的容器。它不負責把粉和熱水混在一起。這篇看的是 2026 年 11 月 1 日官方頁面怎麼寫容量、材質、熱源標示，以及標了給哪一種濾杯用。站長沒有用過這裡列出的壺，不寫味道，也不寫星等。

在壺裡浸泡再壓下去的法壓，是另一種器具，見[法式濾壓壺怎麼挑](/zh-tw/articles/french-press-guide/)。

> **給台灣讀者**：下面的價格是當天官方頁面上的日圓含稅價，不是台灣市價，也不是 Amazon 售價。玻璃的 Range Server 有微波爐標示，沒有明火標示；金屬那款相反，有明火、沒有微波爐。請不要把金屬壺放進微波爐，也不要把沒標明火的玻璃壺放上瓦斯爐。玻璃製品透過 AmazonGlobal 寄到台灣時，不一定每款都能寄；運費與關稅在結帳時顯示，收件人需完成 EZ WAY 實名認證。

## 先看結論

- **要放 V60，而且頁面標示蓋著蓋子也能進微波爐** → HARIO V60 Range Server。頁面上的杯數是 360 為 1–3 杯、600 為 2–5 杯、800 為 2–6 杯。那一頁沒有寫實用容量的毫升
- **Kalita 101 濾杯用** → 300 Server N。**102 濾杯用** → 500 Server N。打開的頁面都沒有寫毫升，這篇不把品名裡的 300、500 當成容量
- **頁面標示可以放明火再加熱的不鏽鋼** → HARIO V60 金屬咖啡分享壺。實用容量 500mL。微波爐沒有標示
- **想用公克把量留住** → 壺上的刻度之外，還需要秤。手沖壺、水溫和電子秤見[讓手沖再升級的器具](/zh-tw/articles/hand-drip-upgrade-gear/)。配方裡的 12g、24g，沒辦法只靠壺上的杯數重現

## 壺口要和濾杯對上

### HARIO V60 Range Server

官方寫：有約略的刻度和杯子標示、蓋著蓋子可以進微波爐、蓋著蓋子也能放上 V60 濾杯，收納方便。01、02、03 哪一個尺寸放得上去，打開的頁面沒有寫號碼。能放的尺寸請在購買頁確認。

熱水、微波爐、洗碗機有標示，烤箱、感應爐、明火沒有。請當成不能把玻璃放上火。HARIO 手沖配方裡的一杯 120mL，是另一份使用說明 PDF 上的數字，和這一頁的「1–3 杯」不是同一頁。不要只靠這台壺的頁面，去換算一杯有幾毫升。

[在 Amazon.co.jp 搜尋 HARIO V60 Range Server](https://www.amazon.co.jp/s?tag=stocknotelife-22&k=HARIO+V60+%E3%83%AC%E3%83%B3%E3%82%B8%E3%82%B5%E3%83%BC%E3%83%90%E3%83%BC)

### Kalita 300 Server N 與 500 Server N

頁面寫 300 Server N 給 101 濾杯、500 Server N 給 102 濾杯。兩者都是耐熱玻璃、泰國製。300 的本體尺寸是 148×103×103mm，本體重量 180g，商品重量 240g。500 是 155×122×115mm，本體 235g，商品重量 305g。

打開的頁面沒有寫滿水容量的毫升。品名裡的 300 和 500，這篇不把它們叫成毫升。能不能放 Wave 濾杯，這兩頁也沒寫。用 Wave 的人，請對一下壺上「適用哪一種濾杯」的標示。

Kalita 的常見問題裡，針對該公司耐熱玻璃的一般說明是：耐熱溫差 120℃ 不是「只能用到 120℃」，而是急熱急冷的溫差。這不是本站把 300 Server N 和 500 Server N 的個別試驗結果轉載過來。不要放明火、不要放烤箱、不要空燒，也是那一頁對玻璃的一般文句。

[在 Amazon.co.jp 搜尋 Kalita 咖啡分享壺](https://www.amazon.co.jp/s?tag=stocknotelife-22&k=%E3%82%AB%E3%83%AA%E3%82%BF+%E3%82%B3%E3%83%BC%E3%83%92%E3%83%BC%E3%82%B5%E3%83%BC%E3%83%90%E3%83%BC)

### HARIO V60 金屬咖啡分享壺

戶外向的頁面寫：可以放明火再加熱、三角形不容易讓香氣散掉。實用容量 500mL，型號 O-VCSM-50-HSV，含外盒約 400g，建議零售價含稅 4,400 日圓。本體、蓋子、握把是不鏽鋼，原產國中國。

有標示的是熱水、洗碗機、明火。微波爐沒有標示。不要把它當成可以進微波爐的金屬容器。和玻璃的 Range Server 比，再加熱的地方不一樣。

[在 Amazon.co.jp 搜尋 HARIO V60 金屬咖啡分享壺](https://www.amazon.co.jp/s?tag=stocknotelife-22&k=HARIO+%E3%83%A1%E3%82%BF%E3%83%AB%E3%82%B3%E3%83%BC%E3%83%92%E3%83%BC%E3%82%B5%E3%83%BC%E3%83%90%E3%83%BC)

搜尋結果會混進濾杯和馬克杯。請在商品名稱裡對一下它是分享壺，以及型號。

## 接咖啡的容器，和沖煮的道具是兩件事

有了壺，沒有秤的話，隔天還是回不到同樣的粉量和水量。細口壺、水溫和電子秤見[讓手沖再升級的器具](/zh-tw/articles/hand-drip-upgrade-gear/)。

不鏽鋼濾網裝在壺上、在壺裡直接萃取的，是另一種道具。KINTO SCS 在[冷泡・戶外咖啡](/zh-tw/articles/cold-brew-outdoor-coffee/)裡介紹過，站長沒有用過。它和這篇的分享壺做的事不一樣。

想現磨的話，放在家裡用的是[栗子 S5 Pro](/zh-tw/articles/timemore-chestnut-s5-pro/)，想轉起來比較輕的是 [Essence Go](/zh-tw/articles/epeios-essence-go/)。S5 Pro 官方的手沖刻度是 5.0–8.0，出處在那篇評測，只是起點。站長用狩獵綠的 S5 Pro，用法以手沖為主。
