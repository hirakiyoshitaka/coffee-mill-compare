結論を先に一本にはしません。コマンダンテ C40 MK4 とタイムモア Chestnut X は、どちらも手挽きのフラッグシップとして名前が挙がりますが、取りにいくものが違います。この記事は「買うべき一台」の宣言ではなく、掲載データで分岐を作るためのノートです。価格は目安です。

対象は次の2つだけです。

- コマンダンテ（ドイツ）Comandante C40 MK4
- タイムモア（中国）Timemore Chestnut X

## 違って見えるところ

| 項目 | C40 MK4 | Chestnut X |
| --- | --- | --- |
| バー | 窒化鋼（Nitro Blade） | S2C 880 ステンレス（特許形状） |
| バー径 | 39 mm | 公表値要確認 |
| 粒度調整 | ダイヤル式ステップ（クリック） | 24段階＋微調整リング |
| 重量 | 600 g | 765 g |
| 価格の目安 | 約45,000〜55,000円台（リテーラー・為替により変動） | 約35,000〜45,000円台（セール・店舗により変動） |

バーの素材も、調整の仕組みも、名前の付け方が違います。径は C40 だけ 39mm と分かっていて、Chestnut X はデータに公表値がありません。径の大小で優劣は付けられません。

重量は 600g と 765g です。掲載値では C40 の方が軽い。Chestnut X の留意点には、サイズと重量が携帯より据え置き寄り、と書いてあります。

## C40 を先に開く人

次のどれかが、自分の条件に近いなら、先に C40 のページを見てください。

- ハンドドリップからカップまでのバランスを、機種の位置づけとして知りたい。データは「バランス型」と書いています。
- 粒子の均一さと、甘みの出方についての定評を取りにいきたい。
- クリックの段で、挽き目を戻したい。
- 600g の方が、765g より扱いやすいと感じる。
- ビルド品質や、手放したあとの値の残りやすさ（リセール）が気になる。
- 価格の目安が約45,000〜55,000円台でも、検討の範囲に入る。

コミュニティの要約では、味の輪郭と甘みは好意的な傾向です。同じ豆でも雑味が減り、輪郭がはっきりする、という体験談が多い、とあります。これは味の保証ではなく、繰り返されている論点です。

価格については賛否があります。初めての一台としては勇気が要り、長く使うなら投資として妥当、という両方です。留意点にも「価格帯が高め」とあります。

## Chestnut X を先に開く人

次に近いなら、Chestnut X からです。

- デザインと、支払う金額のバランスを先に見たい。データは「デザイン性とコストパフォーマンスの両立を狙う層に人気」と書いています。
- 価格の目安を、約35,000〜45,000円台（セール・店舗により変動）の帯から確認したい。C40 より起点が低いです。
- 24段階と、微調整リングの組み合わせを試したい。
- キッチンに置いたまま使うので、据え置き寄りでも困らない。データもその留意点を挙げています。

口コミの傾向では、コスパと見た目が好意的です。同価格帯の欧州ブランドと並べても完成度が高い、という評価が繰り返される、と要約されています。微調整と極細域は賛否、メンテナンスは要検討です。分解して掃除しやすいという声と、パーツが手に入るかを気にする声が混在します。

## 両方に残る、決めきれないところ

エスプレッソの極細では、優劣を付けません。C40 は「可能だが、習熟と時間が必要」という声があります。Chestnut X は「極細域の再現性に、個体差やメンテナンスの影響がある」という指摘があります。文言が違うので、同じ欠点だとまとめるのは正確ではありません。どちらも、専用の電動ミルの代わりだとはデータに書いてありません。

価格の帯は、45,000円台で触れ合います。Chestnut X の上端と、C40 の下端です。目安の紙の上で「いつも Chestnut X の方が安い」とは言い切れません。見るべきなのは、いま開いている店の数字です。

味の好き嫌いは、この2機種を同じ豆で飲み比べた結果としては載っていません。均一さや甘みの定評は C40 のメモ、切れ味とスルー速度は Chestnut X のメモです。軸が違うので、甘い方がどちらかはここからは出ません。

## 迷ったときの手順

1. 予算の上限が、目安で 35,000〜45,000円台に収まるなら、Chestnut X の販売ページを先に開く。
2. 45,000〜55,000円台まで見て、ハンドドリップのバランスと甘みの定評を取りにいくなら、C40 を先に開く。
3. 店頭の価格が目安の帯から外れていたら、帯の話は捨てて、調整の好み（クリックか、段階＋リングか）と、600g か 765g かで選ぶ。
4. 細挽きの外ダイヤルが気になり始めたら、この二択の外です。[K-Ultra を含む3機種の記事](/articles/manual-grinders-comandante-timemore-1zpresso/)に、48mm・外ダイヤル・価格の目安約28,000〜38,000円台がまとまっています。

無段階の据え置きで、さらに上の価格帯を見るならキヌ M47 Classic です。価格の目安は約55,000〜75,000円台（輸入ルート・在庫により変動）です。この記事の範囲外なので、詳細は[ミルの全体記事](/articles/coffee-mill-ranking/)と[比較表](/compare/)に譲ります。

購入リンクを設置している場合、それは広告です。未設定の機種にはボタンが出ません。

## 挽いたあとに頼む豆

C40 と Chestnut X のどちらを置くかと、どの店の豆を頼むかは別です。店の紹介は[豆の店](/beans/)に、手挽きを買ったあとの豆の入口は[手挽きミルを買ったら最初に頼みたい豆](/articles/first-beans-after-hand-mill/)に分けています。この2機種と特定の豆の味の組み合わせは、載せていません。
