分享壶是放在滤杯底下、接萃取液的容器。它不负责把粉和热水混在一起，也不是细口手冲壶。这篇看的是 2026 年 11 月 1 日官方页面怎么写容量、材质、热源标示，以及标了给哪一种滤杯用。本站没有用过这里列出的壶，不写味道，也不写星级。

在壶里浸泡再压下去的法压，是另一种器具，见[法压壶怎么选](/zh-cn/articles/french-press-guide/)。用炉火把水压上来的摩卡壶，见[摩卡壶怎么选](/zh-cn/articles/moka-pot-guide/)。想改由机器做接近手冲的滴滤，见[巴慕达 The Brew 和双鸟全自动](/zh-cn/articles/japanese-premium-coffee-makers/)。手冲前若要按用途分手摇，见[1Zpresso 手摇磨豆机怎么选](/zh-cn/articles/1zpresso-hand-grinder-lineup/)。

## 在中国大陆看这些壶

下面的价格是当天官方页面上的日元含税价，不是国内零售价，也不是亚马逊售价。玻璃的 Range Server 有微波炉标示，没有明火标示；金属那款相反，有明火、没有微波炉。不要把金属壶放进微波炉，也不要把没有标明火的玻璃壶放上燃气灶。

玻璃制品从 Amazon.co.jp 寄出时，不一定每款都能寄。能否寄到你的地址、运费和关税，以结算页为准。

## 先看结论

- **要放 V60，而且页面标示盖着盖子也能进微波炉** → HARIO V60 Range Server。页面上的杯数是 360 为 1–3 杯、600 为 2–5 杯、800 为 2–6 杯。那一页没有写实用容量的毫升
- **Kalita 101 滤杯用** → 300 Server N。**102 滤杯用** → 500 Server N。打开的页面都没有写毫升，这篇不把品名里的 300、500 当成容量
- **页面标示可以放明火再加热的不锈钢** → HARIO V60 金属咖啡分享壶。实用容量 500mL。微波炉没有标示
- **想用克把量留住** → 壶上的刻度之外，还需要秤。配方里的 12g、24g，没办法只靠壶上的杯数重现

## 壶口要和滤杯对上

### HARIO V60 Range Server

官方写：有大致的刻度和杯子标示、盖着盖子可以进微波炉、盖着盖子也能放上 V60 滤杯，收起来方便。01、02、03 哪一个尺寸放得上去，打开的页面没有写号码。能放的尺寸在购买页确认。

热水、微波炉、洗碗机有标示，烤箱、电磁炉、明火没有。把它当成不能把玻璃放上火。HARIO 手冲配方里的一杯 120mL，是另一份使用说明 PDF 上的数字，和这一页的「1–3 杯」不是同一页。不要只靠这把壶的页面，去换算一杯有几毫升。

[在 Amazon.co.jp 搜索 HARIO V60 Range Server](https://www.amazon.co.jp/s?tag=stocknotelife-22&k=HARIO+V60+%E3%83%AC%E3%83%B3%E3%82%B8%E3%82%B5%E3%83%BC%E3%83%90%E3%83%BC)

### Kalita 300 Server N 与 500 Server N

页面写 300 Server N 给 101 滤杯、500 Server N 给 102 滤杯。两者都是耐热玻璃、泰国制。300 的本体尺寸是 148×103×103mm，本体重量 180g，商品重量 240g。500 是 155×122×115mm，本体 235g，商品重量 305g。

打开的页面没有写满水容量的毫升。品名里的 300 和 500，这篇不把它们叫成毫升。能不能放 Wave 滤杯，这两页也没写。用 Wave 的人，对一下壶上「适用哪一种滤杯」的标示。

Kalita 的常见问题里，针对该公司耐热玻璃的一般说明是：耐热温差 120℃ 不是「只能用到 120℃」，而是骤热骤冷的温差。这不是本站把 300 Server N 和 500 Server N 的个别试验结果转载过来。不要放明火、不要放烤箱、不要空烧，也是那一页对玻璃的一般文句。

[在 Amazon.co.jp 搜索 Kalita 咖啡分享壶](https://www.amazon.co.jp/s?tag=stocknotelife-22&k=%E3%82%AB%E3%83%AA%E3%82%BF+%E3%82%B3%E3%83%BC%E3%83%92%E3%83%BC%E3%82%B5%E3%83%BC%E3%83%90%E3%83%BC)

### HARIO V60 金属咖啡分享壶

户外向的页面写：可以放明火再加热、三角形不容易让香气散掉。实用容量 500mL，型号 O-VCSM-50-HSV，含包装盒约 400g，建议零售价含税 4,400 日元。本体、盖子、握把是不锈钢，原产国中国。

有标示的是热水、洗碗机、明火。微波炉没有标示。不要把它当成可以进微波炉的金属容器。和玻璃的 Range Server 比，再加热的地方不一样。

[在 Amazon.co.jp 搜索 HARIO V60 金属咖啡分享壶](https://www.amazon.co.jp/s?tag=stocknotelife-22&k=HARIO+%E3%83%A1%E3%82%BF%E3%83%AB%E3%82%B3%E3%83%BC%E3%83%92%E3%83%BC%E3%82%B5%E3%83%BC%E3%83%90%E3%83%BC)

搜索结果会混进滤杯和马克杯。在商品名称里对一下它是分享壶，以及型号。

## 接咖啡的容器，和冲煮的器具是两件事

有了壶，没有秤的话，隔天还是回不到同样的粉量和水量。12g、24g 和壶上印的杯数不是同一件事。

不锈钢滤网装在壶上、在壶里直接萃取的，是另一种器具。KINTO SCS 就是这一类，本站没有用过。它和这篇的分享壶做的事不一样。

想现磨的话，放在家里用的是栗子 S5 Pro，想转起来比较轻的是 Epeios Essence Go。S5 Pro 官方的手冲刻度是 5.0–8.0，只是起点。简体中文版还没有这两台的单独测评，下面的卡片用的是本站已有的规格和购买链接。站长每天用的是泰摩栗子 S3。一次大约磨 30g，做 2–3 杯。没有在用栗子 S5 Pro。
